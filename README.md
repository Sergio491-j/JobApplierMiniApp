Este es un proyecto personal en desarrollo y sin fines de lucro ni fines maliciosos.
Se trata de un bot que mappea ofertas de la ETT RandStand desde su web, el bot recopila ofertas de la aplicación 
dado a un filtro y este las mete en una base de datos para acto después enseñarlas al usuario.
